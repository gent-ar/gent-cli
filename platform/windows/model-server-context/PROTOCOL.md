# Zero-network upstream server-context adapter (experimental)

This optional Windows component calls unmodified llama.cpp b10545 `server_context` / `server_routes` directly. It never constructs, initializes or starts `server_http_context`. No HTTP socket listener is needed. `LLAMA_SUBPROCESS=OFF`, `LLAMA_OPENSSL=OFF`, GPU/RPC backends off, CPU static and a single compile job are required in the verified build. It is not selected by Gent's Claurst factory yet.

The trusted launcher must retain and verify exact worker, selected GGUF, OS loader closure and optional template identities, and own the zero-network PSEC Job throughout the run. Use finite read-only grants; no recursive model/runtime grants, user configuration inheritance or credential argv. The worker uses one CPU thread, a 1024-token context, one model/slot and a 64-token generation ceiling. These are deliberately bounded acceptance limits, not general installed-model readiness.

Command: `worker selected-model.gguf nonce32 [template-file template-sha256]`. Default uses the GGUF's native upstream template; the optional override is the same upstream template-source input, never manual message concatenation. Its ordinary non-reparse file is bounded to128KiB, SHA256-checked and retained without write/delete sharing. The parent must also validate its path ancestry and bind it into the model profile. All authority is the parent's typed model/runtime pins plus native launch proof; nonce alone is not authority.

Private inherited stdin begins with ASCII `GENTSR01` and 32 lowercase nonce bytes. After loading the model, stdout emits `GENTSD01` and that nonce. Verify/consume the native helper's distinct lifecycle proof first. Integers are little-endian u32. Request: length then UTF-8 JSON envelope with exactly method/path/body strings; body is the original HTTP-body string. Length<=262144, body<=131072, path<=128; at most32 serial requests. Length0 closes normally. Enforce one outstanding request per channel. Allowed routes: GET /health, GET /v1/models, POST /v1/chat/completions, POST /apply-template. Other paths return404, including file/slot/control routes. Function tools only; generation-limit aliases, when present, must each be integral1..64 and at least one must be present. No tool is executed by this adapter.

Response begins with one length-prefixed JSON metadata frame (<=32768): status/contentType/headers/stream. Following nonempty byte frames (<=32768 each) preserve the upstream JSON body or exact SSE bytes; length0 terminates the response. Maximum body4MiB. Streaming forwards each generator chunk, including the final chunk returned with `next=false`; it does not reconstruct content or tool deltas. Framing boundaries can split UTF-8/SSE events: the host must decode incrementally and obey SSE framing. Partial/truncated/error output is never success. Upstream HTTP errors remain status+body (the actual toy-GGUF grammar400 was preserved). Invalid JSON maps400; the next valid request can reuse the worker. Resource/protocol failure retires the process.

EOF/revoke/cancel retires the entire owned PSEC scope through the outer helper; no in-place request cancellation/cache-reuse claim is made. The current route callback's should_stop is false because cancellation authority is the outer Job, not an unauthenticated peer signal. The caller must await exact Job settlement and retain model/runtime pins on Unknown. A helper wait alone is insufficient. Graceful length0 shutdown and native ScopeSettled0 were observed; full factory/revocation composition remains required before enablement.

## Build source

Verified upstream archive: https://codeload.github.com/ggml-org/llama.cpp/zip/refs/tags/b10545, SHA256 9f33a1308e4eb52b3c706159da5e182a9df9d195d41be1d660dd3dff7fe97911. Verify that digest before extraction into an owned stage. Add this directory via add_subdirectory from that upstream root (its server-context target is the dependency), then configure normal MSVC/Ninja Release, BUILD_SHARED_LIBS=OFF, GGML_NATIVE=OFF, GGML_BACKEND_DL=OFF, GGML_CPU_ALL_VARIANTS=OFF, GGML_OPENMP=OFF, GGML_CUDA=OFF, GGML_RPC=OFF, LLAMA_OPENSSL=OFF, LLAMA_SUBPROCESS=OFF, LLAMA_BUILD_TESTS/EXAMPLES/APP/UI=OFF, LLAMA_USE_PREBUILT_UI=OFF, LLAMA_BUILD_TOOLS/SERVER=ON. Use /MT and build only gent-contained-server-context with --parallel1. Acceptance used /O1 to bound compilation memory. Upstream is MIT; model data are separate and are not redistributed here.
